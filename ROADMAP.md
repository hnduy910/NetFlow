# NetFlow Roadmap

NetFlow is developed in small, testable releases. The roadmap is intentionally lightweight and may change based on user feedback.

## Near term

- Expand unit coverage for data-plan cycle boundaries, rollover, persistence, and usage forecasting.
- Improve accessibility and Dynamic Type behavior across compact iPhone layouts.
- Add clearer documentation for network endpoints used by optional IP, weather, and geocoding features.
- Continue English/Vietnamese localization review and welcome community translations.

## Later

- Evaluate an optional WidgetKit target for glanceable usage information.
- Explore App Intents / Shortcuts for refresh and report-export workflows.
- Add richer trend analysis without introducing an account or backend requirement.

## Principles

- Local-first usage data
- Native Apple frameworks where practical
- Minimal dependencies
- Features that remain useful on standard signing and clearly document capability limitations

Suggestions and focused pull requests are welcome.
